# BhaktiAI — AI-Powered Devotional Companion

A hackathon-ready frontend prototype for a devotional knowledge platform.

## Problem
Indian devotional and cultural knowledge can feel difficult for younger audiences to discover and understand. Information is spread across many sources and is often presented in complex language.

## Solution
BhaktiAI is an AI-powered devotional companion concept that makes stories, scriptures, festivals, prayers, temple traditions and cultural knowledge easier to explore.

## Key Features
- Conversational devotional Q&A interface
- Topic exploration for stories, festivals, scriptures and temples
- Daily reflection / devotional thought
- Mobile responsive design
- RAG-ready architecture concept: curated knowledge → retrieval → AI explanation
- Friendly, modern interface designed for younger users

## Tech Stack
HTML, CSS, JavaScript.  
The current version is a frontend prototype. A production version can connect the chat interface to a backend, vector database and LLM API.

## Future Scope
1. Add a curated devotional knowledge base.
2. Add embeddings + vector search for RAG.
3. Connect an LLM for natural-language answers.
4. Show source references for every answer.
5. Add Telugu, Hindi and other Indian languages.
6. Add temple discovery and festival calendar.
7. Add voice input/output for accessibility.

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Hackathon pitch
"BhaktiAI bridges India's devotional knowledge and modern AI. Instead of making young people search through scattered information, we give them a simple conversational way to discover stories, traditions and spiritual ideas—with a future-ready RAG architecture designed to keep answers grounded in curated sources."
